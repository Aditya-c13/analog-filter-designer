# analog-filter-designer
An interactive Python &amp; Streamlit platform for continuous-time analog filter synthesis, s-plane ZPK analysis, E24 component quantization, Monte Carlo tolerance runs, and automated report export.

In the command prompt, navigate to folder where the files are extracted. This can be done by copying the file path of the folder and running "cd /d <folder_path>" on command prompt. 
Execute "pip install -r requirements.txt" to install all the dependencies.
Launch the application using the command "streamlit run analog_filter_app.py"
